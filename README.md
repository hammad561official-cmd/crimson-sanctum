# Crimson Sanctum

**An Interactive Portfolio Experience**

A cinematic, performance-conscious portfolio built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and selectively used Three.js/React Three Fiber.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```
